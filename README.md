This repo is the converted React version of the original static HTML/CSS/JS college portal.

Quick start (Windows PowerShell):

```powershell

```

Open http://localhost:5173 in your browser (Vite will print the exact URL).
# College Portal - Modern React Application

A modern, responsive college portal built with React, Vite, and contemporary UI/UX design principles.

## ✨ Features

### 🎨 Modern Design System
- **Gradient-based color palette** with carefully chosen primary and accent colors
- **Glass morphism effects** with backdrop blur for modern visual appeal
- **Smooth animations and transitions** using CSS cubic-bezier timing functions
- **Typography hierarchy** using Inter and Poppins fonts for optimal readability
- **Responsive design** that works seamlessly across all devices

### 🖼️ Enhanced UI Components
- **Hero section** with animated background patterns and hover effects
- **Form inputs** with focus states, smooth transitions, and validation feedback
- **Buttons** with gradient backgrounds, hover animations, and loading states
- **Cards and panels** with subtle shadows and glass effects
- **Dashboard stats** with interactive hover animations

### 📱 Pages Included
- **Home Page**: Welcoming landing page with call-to-action buttons
- **Login Page**: Secure authentication with role-based access
- **Register Page**: User-friendly registration without role requirement
- **Dashboard**: Personalized dashboard with statistics and quick actions

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd for-sara-web
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   - Navigate to `http://localhost:5173` (or the port shown in terminal)

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
